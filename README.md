# 远雨来信 · AIGC 插画与分镜档案

一个无需构建、无需后端的纯静态多页面网站。包含三本彼此独立的原创绘本，每本故事各有主角、世界观和结局；每条主线含 12 格文字分镜与 12 幅对应插画，共 36 幅本地 WebP 插画。

可以直接打开 index.html 浏览。若要让收藏与阅读进度在这 13 个页面之间稳定共用，建议双击 start-site.bat；它只在本机启动 Python 自带的静态文件预览，不提供后端功能。网站不加载远程图片、字体、脚本或接口，阅读历史、收藏与创作草稿仅保存在当前浏览器。

## 独立页面

- index.html：故事选集与阅读桌
- moon.html、harbor.html、whales.html：三个单独的故事档案
- read-moon.html、read-harbor.html、read-whales.html：各自的分镜阅读器
- gallery.html：36 幅插画的搜索、故事筛选、排序、网格/列表和收藏筛选
- atlas.html：三条可切换的故事路线地图，地点可跳转对应分镜
- characters.html：三本故事的人物和配角档案
- studio.html：本地分镜提示词编排、复制与导出
- shelf.html：收藏、阅读历史和本地草稿
- about.html：原创内容、AI 与人工创作分工及作品流程
- start-site.bat：可选的本机静态预览启动器

## 可用功能

- 阅读器支持上一格/下一格、12 格缩略导航、章节跳转、自动播放、阅读进度恢复、浏览器语音朗读、字号调节、专注模式和当前画面分享
- 插画支持大图浏览、前后切换、全屏、收藏和下载
- 全站支持日间/夜间主题；阅读器支持键盘左右方向键翻页
- 画廊按标题、场景地点和文字描述搜索，按故事筛选、切换排列和查看收藏
- 分镜实验室会根据故事、画面、构图与色彩选项组合提示词，并可编辑、复制、保存至本地或导出

## 文件结构

- story-data.js：三本故事、36 格正文、人物和路线数据
- app.js：页面渲染与本地交互
- styles.css：多页面样式与移动端适配
- assets/：36 幅本地插画、创作提示记录
- assets/ART-DIRECTION.md：插画方向、场景提示和创作过程说明

提示词实验室负责本地分镜策划，不会冒充云端图像生成服务。图像资产由生成式图像工具生成，经人工筛选、命名、排序和故事校准。
